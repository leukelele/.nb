# basic CPU concepts

At its core, the CPU functions as an exceptionally fast calculator, performing arithmetic and logical operations that serve as the foundation for all computing tasks.






Taking a step back, first answer this question? How does one communicate with a switch? The switch is assigned a meaning: 0/1 - the assignment of each label to which side does not matter, what matter is the representation. Now a switch is able to communicate binary concepts. Now how would you communicate more complex topics? Stringing multiple switches together and assigning meaning to each combination of 0/1s. This assigned meaning is determined by the CPU instruction set.

The CPU reads in theses 0/1s and performs an action based on the assigned meaning, instruction. It receives an input -> processes it -> returns an output. But then where does the output go? It goes to the external data bus which serves as means for the CPU to communicate with the rest of the computer system.

Registers are components w/in a CPU that offer immediate access to temporary data. Imagine a workbench, as the brain is the processor that processes information and det.s the next course of action, the registers could be thought of as toolbox right next to you, w/in the immediate tools required for operation.
