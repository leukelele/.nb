## macos

- In MacOS, **mission control**, ctrl + <up>, allows for view of all apps; 
- multiple spaces (workspaces) and may be navigated by ctrl + <left/right> 
- finder is the MacOS equivalent to file explorer 
- MacOS has system preferences and utilities folder (for diagnostics)

## windows

- `dir` is the `ls` command for windows 
- control panel is slowly being replaced by settings 
- 32bit programs will be stored in x86 program file
