> What is the difference between CMAKE and MAKE?[^1]

`make` is a build automation tool primarily designed for Unix-like systems,
such as the GCC compiler suite. It relies on Makefiles to define build rules
and dependencies.

In contrast, `CMake` is a cross-platform build system generator that abstracts
the build process, allowing developers to generate native build files for
various platforms and compilers such as: GCC with Linux, visual studio with
Windows, and xcode with MacOS. A single build configuration is maintained
across these platforms.

> How does MAKE differ to CMAKE?[^1]

In the original, rules were established in the `Makefile`, whereas in `CMake`,
you define the target files and external dependencies that need to be built.
Notably, `CMake` handles all inter-file dependencies. Additionally, it can
check for and download external libraries if needed.

`CMake` reduces direct control over the compiler and linker flags used for the
project, though this can be overridden. While this results in less precise
control, it also reduces the mental burden on the developer.
