# what is a computer?

A **computer** is an electronic device that performs calculations and processes information. While computers are typically designed for general purposes - such as desktops, laptops, and mobile devices - they can also be built for specific tasks, such as Internet of Things (IoT) devices, Point of Sale (POS) systems, and routers. Regardless of the design, all computers follow a common process: receiving input, processing that input, and returning an output.

A computer is composed of three main parts:
    - **hardware**. the physical components of the device; the parts that can be touched or interacted with.
    - **operating system (OS)**. a collection of software that bridges the user and the hardware. The operating system is typically specific to the hardware and provides a user interface (UI) for the user. It also limits the user to a set of compatible apps. Ideally, the OS should allow the user to add, remove, and move apps.
    - **applications**. software programs that run on top of the operating system, designed to perform specific tasks.
